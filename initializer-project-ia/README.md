# Bootcamp IA

AI project using LangChain and Streamlit.

## Tech Stack
- **LangChain**: LLM orchestration.
- **Streamlit**: Web UI.
- **Python**: Core logic.
- **OpenAI/Google GenAI**: LLM providers.

## Requirements
- Python 3.9+
- API Keys (OpenAI or Google)

## Setup
1. Clone repo.
2. Setup virtual environment `python -m venv env` -> `source venv/bin/activate`
2. Install deps: `pip install -r requirements.txt`.
3. Configure `GOOGLE_API_KEY` environment variable.

## Run
`streamlit run app.py`
